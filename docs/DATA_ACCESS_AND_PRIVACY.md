# Data access and privacy

## Data availability

This project used the All of Us Research Program Controlled Tier Dataset v8. The underlying participant-level data are not included and cannot be reconstructed from this repository. Authorized researchers can request access through the [All of Us Researcher Workbench](https://www.researchallofus.org/data-tools/workbench/).

## Public repository safeguards

The repository contains code, aggregate figures, and public-safe course materials only. It excludes:

- participant-level data and identifiers;
- copied notebook output containing participant records;
- workspace bucket paths and account-specific details;
- generated RDS, CSV, and model objects; and
- direct or inferable participant counts of 1 through 20.

Small cells in the original course report and presentation were suppressed in the public copies. The presentation video was likewise edited only to suppress those cells; the scientific content and narration were otherwise retained.

## Required policy review

Anyone adapting this project must comply with the All of Us [Data User Code of Conduct](https://support.researchallofus.org/hc/en-us/articles/22346176432532-Data-User-Code-of-Conduct) and [Data and Statistics Dissemination Policy](https://support.researchallofus.org/hc/en-us/articles/22346276580372-Data-and-Statistics-Dissemination-Policy). Public outputs must not include participant-level data or counts of 1 through 20, whether shown directly or inferable from other reported values.
